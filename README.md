# ✈️ 인천공항고 읽걷쓰AI 미래 항공권 발권기 (Incheon Airport AI Boarding Pass Generator)

> **"읽걷쓰AI, 인간다움을 품고 AI와 함께 꿈을 이루다"**  
> 2026 인천 AI·SW 미래채움 교육페스티벌 **인천공항고등학교** 부스 운영용 웹 애플리케이션

## 📌 주요 기능
- **맞춤형 3줄 시문(詩文) 생성**: 관람객의 이름과 미래 키워드 3가지를 바탕으로 `읽기·걷기` / `쓰기·AI` / `미래·희망` 3줄 시와 미래 목적지 자동 생성
- **하이브리드 AI 엔진**:
  - **내장 읽걷쓰AI 스마트 시학 엔진**: 한국어 조사 자동 판별 및 1,000가지 조합의 시문 템플릿으로 와이파이 연결이나 API 키 없이도 현장에서 즉시 발권 가능
  - **실시간 생성형 AI 연동**: 부스 운영자 설정 모달에서 Google Gemini (`gemini-2.5-flash`) 또는 OpenAI (`gpt-4o-mini`) API Key 연동 지원
- **3×5 포토용지 인쇄 최적화 (`@media print`)**:
  - `5×3 인치 가로 포토용지 (127×76mm)`, `3×5 인치 세로 포토용지`, `A4 중앙 인쇄` 완벽 지원
- **고해상도 PNG 티켓 다운로드**: `html2canvas` 기반 3배율 고해상도 이미지 즉시 저장
